## What it actually is

The runtime is a **decorative canvas layer**: host owns box and background; field enforces `pointerEvents: none`, `aria-hidden`, clipping, and optional second canvas for links. It watches pointer events but does not own hit testing, pointer capture, placement, or object state. The package exports only the component and a per-instance controller. [Renderer/DOM](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L2712-L2724), [exports](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/index.ts), [architecture](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/docs/ARCHITECTURE.md#L3-L11).

The demo has two actual integrations: three draggable/resizable cards on one field, and a React Flow editor with the field behind its transparent graph. The playground sends its layout and active footprint through one controller. The Flow bridge subscribes to React Flow's store, sends viewport and node boxes on the same tick, and reserves React renders for the host's semantic UI. [Playground](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/demo/src/PlaygroundDemo.tsx#L22-L79), [Flow bridge](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/demo/src/FlowDemo.tsx#L84-L181), [standalone example](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/examples/react-flow/FlowWithField.tsx#L167-L190).

## Principles worth adapting

| Principle | Source evidence and mechanism | MetalUI question, rather than an upstream feature to copy |
| --- | --- | --- |
| **The surface responds to the real scene, not inferred DOM decoration.** | The host submits committed object rectangles, IDs, and parent IDs; it separately submits transient footprints and previews. The field never discovers objects itself. A scene is retained across a late mount; gesture transients are intentionally discarded. [Controller types/retention](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/controller.ts#L12-L45), [subscription](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/controller.ts#L55-L95). | Should a Canvas Place own the scene and publish one spatial snapshot, so Region state, placement, and field response share facts? |
| **The room owns layout and meaning; the field owns only rendering.** | Host supplies size, background, interaction root, and theme conventions. `setScene` is an adapter from host object geometry; `setFootprint` is an adapter from host gesture data. The package is clear that it is decorative, while demo cards provide labeled keyboard handles. [Integration](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/docs/INTEGRATION.md#L3-L13), [keyboard handles](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/demo/src/SurfaceCard.tsx#L15-L34). | Region should keep acceptance rule, label, count, and drop semantics. A shared field may make its spatial relation visible, but cannot decide what accepts an object. |
| **Each visual response must have a cause and a priority.** | A programmatic ring uses an event identity (`at`), so another render cannot repeat it. Press, carried object, marquee, preview, and release are distinct sources; marquee suppresses the press ring. Held object shape grows in over 90 ms; release sends a wave from its edge. A held press outranks a zoom wave when ring capacity is full. [Event identity](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L97-L120), [gesture policy](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L638-L680), [prepared source priority](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L1100-L1125), [marquee/footprint](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L2470-L2512). | Define rest, carry, possible target, commit, and cancel as one state machine; choose which feedback wins when they overlap. A generic pointer ripple can misstate placement intent. |
| **An object's shape matters more than pointer position.** | Scene and carried footprints clear their **interior and boundary**, with a separately tunable outside fade. Waves measure distance to a rectangle's edge rather than its center; region-like nested containers let child exteriors reclaim the parent's empty interior. [Shape taper and nesting](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L1084-L1091), [taper/nesting](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L1154-L1189), [edge wave](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L1199-L1227). | Give objects and Regions explicit geometry, radius, and containment; don't derive a visual halo from just the cursor. Generalize to authored shapes only after rectangles prove the contract. |
| **One spatial floor has persistent phase.** | The dot lattice keeps index identity while panning and zooming. Panning moves dots 1:1; zoom changes spacing by `clamp(zoom^0.4, 0.7, 1.6)` around the gesture's inferred anchor. The renderer carries the lattice from camera to camera instead of recalculating it from an offscreen world origin, which would visibly jump. Light, rings and measured rectangles stay in screen CSS pixels. [Coordinate design](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/viewport.ts#L1-L23), [lattice transform](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/viewport.ts#L166-L205), [camera application](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L2019-L2052). | A Place-wide field needs one phase and one coordinate contract across Regions, nested objects, scroll, zoom, and device scale. Decide if dots are a physical floor or a screen texture before choosing parallax. A visible dot lattice must not imply a snap grid unless spacing really is a constraint. |
| **Committed scene and gesture stream have different lifetimes.** | `scene` and camera replay on remount; footprint and preview do not. Within the renderer, scene maps by stable ID; a moved object invalidates old and new boxes. Gesture updates enter the renderer without React rerendering; latest camera values coalesce to one frame. [Controller state](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/controller.ts#L55-L95), [scene reconciliation](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L518-L553), [camera coalescing](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L2019-L2028). | Keep model state replayable and input previews disposable. An instance-owned bridge can feed a renderer while the host remains authoritative for drop rules. |
| **Ambient rendering has a duty cycle, not just a frame rate.** | The author documents how wandering light and continuous breath kept expensive work alive on an idle canvas. The implementation sleeps when settled, dozes at ~22 Hz for breath-only work, pauses when the document is hidden, and repaints after theme changes even when asleep. Camera changes cause a full repaint, while local motion uses dirty regions and unchanged-cell checks. [Idle reasoning](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L683-L708), [cell change checks](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L1319-L1369), [breath duty cycle](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L1999-L2028), [settlement](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L2170-L2263), [visibility/theme](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L2558-L2606). | Set a budget for a quiet Place: no perpetual active frame loop unless the material behavior earns it. React and Swift must both suspend offscreen and repaint on state/theme changes. |
| **Visual properties need perceptual trials, not just numeric tokens.** | Source comments record failed attempts: too few breathing dots look like isolated incidents; too many read as unstable shimmer; a slow low-contrast fade can become invisible. ## Important boundaries and caveats

1. **Upstream `setScene` does not represent target eligibility, drop rule, acceptance, or Region state.** It accepts object rectangles and parent IDs; any MetalUI canvas/Region contract must own placement meaning itself. [Controller types](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/controller.ts#L5-L46), [integration boundary](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/docs/INTEGRATION.md#L3-L13).
2. **Its rectangle model is axis aligned and pixel based.** Scene rects are root-border-box CSS pixels; gestures and previews are viewport CSS rects, converted at the field boundary. It does not natively express rotated, irregular, or rounded silhouettes. A host must republish geometry after layout/scroll/zoom changes. [API coordinates](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/docs/API.md#L41-L53), [renderer conversion](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L518-L532).
3. **Theme and motion integration are host dependent.** Color comes from inherited CSS `color`; tint normally reads a document-root custom property. Only root `class` mutations are observed automatically, so an ancestor theme switch requires `refreshTheme`. The reduced-motion query is read when the effect mounts, with no change listener; a live preference change needs an effect restart/remount or a MetalUI-owned adaptation. `still` may still breathe; only reduced motion stops both. More seriously, this source appears to miss scene repaints in reduced motion: `onScene` sets `sceneDirty` and calls `wake`, but `wake` returns when `looping` is false, and the subscription occurs after the initial `resize()`/render. Thus a retained scene at mount or subsequent scene updates can remain visually stale until another event forces a render. This is a source-path inference to verify in a browser before claiming it as an observed bug. [Theme reads](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L304-L367), [motion flags](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L277-L302), [scene and subscription](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L2543-L2557), [wake](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L2321-L2343), [mount ordering](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L2608-L2628).
4. **The default appearance is an effect, not a ready MetalUI Place recipe.** Defaults include wandering light and breath; the demo's *workspace* preset disables both and sets `tint: 0`, while *ambient* and *mesh* tune them differently. Treat the demo as evidence for contextual recipes and authored thresholds, not evidence that one universal animated field should sit below every Region. [Default props](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/SurfaceField.tsx#L18-L47), [presets](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/demo/src/FieldControls.tsx#L33-L54).
5. **Verification is narrower than a cross-platform product guarantee.** CI runs typecheck, package tests and builds; viewport tests cover camera continuity. A separate Electron script checks a drag, empty object interior, theme round-trip and incremental repaint but is not invoked in CI. Upstream has no Swift renderer or Region/drop semantics. [CI](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/.github/workflows/ci.yml#L7-L26), [viewport tests](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/src/viewport.test.ts#L86-L165), [repaint script](https://github.com/angelolibero/surface-field/blob/89fbf61440a03f057652383bd78aa597d9b41e25/scripts/repaint-regression.cjs#L25-L55).

## Design test for MetalUI

The strongest adoption is a **spatial contract for Places**: one host owns canvas coordinates, object/Region identity, placement eligibility and gesture phase; an optional decorative renderer reads that snapshot and provides causally bounded response; each Region remains responsible for its material, rule and accessibility. Start with one Region feature slice and test whether the field improves understanding of containment and destination. If a canvas context uses dots at rest, keep their phase continuous; other contexts can stay dot-free until an interaction calls for a spatial response. Add a carry/target response only when the host can prove which object and target caused it. This is an inference from the principles above, not an upstream API recommendation.

## Adopt the rule in layers

1. **Foundation decision.** Specify world/viewport conversion, optical distance, event priority, and when a Place may paint at rest. Review two same-size specimens: Region paper on a blank canvas, and a subdued continuous field. Keep the existing Region material and upper-left material light in both. Decide by whether the spatial relationship becomes clearer, including Bone, Graphite, zoom and reduced motion.
2. **One Region interaction.** Feed one host projection to a two-Region, one-object specimen. The projected object center/footprint selects one eligible target; Region `over`, written drop rule, and the optional field response consume that choice. Commit still runs the host's actual drop operation and then updates count. Cancel clears every transient. This is a feature-slice acceptance check, not a new generic background effect.
3. **Canvas adoption.** If the Region slice helps, make the decorative field a Part that a Canvas Place can compose once. A stable instance receives committed scene/camera snapshots and ephemeral gesture projections. It must not start one renderer per Region or inspect DOM for objects. Expose a small semantic contract to React and Swift; keep render algorithms private.
4. **Performance and parity gate.** Repaint only on scene/camera/theme/gesture changes; bound work in dense scenes; stop offscreen/hidden; render reduced motion as a fresh static state after *every* scene update. Verify the actual carried footprint, target text, cancellation, keyboard path, and optical parity in both colorways and both platforms.

This sequence preserves MetalUI's existing strength: Region is a meaningful Place with rule and content, not a visual container. The added principle is **spatial feedback derived from the same projected action that drives the Place**. Dot motion is one possible rendering of that principle.
